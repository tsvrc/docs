## Purpose

A second, independent verification pass over every already-published doc page in
`docs/tsvrc/`. Unlike the original authoring pass (tracked in `TSVRC-DOCUMENTATION-PLAN.md`),
this pass re-reads every doc page against:

1. The actual current source in `D:\vrc\tsvrc` (`.cs` files, not memory of them) — every
   factual claim, every method/field name, every described behavior.
2. The actual test files for that source, where they exist — to catch claims that go beyond
   what the code visibly guarantees, or that contradict a test.
3. Real usage patterns in `D:\vrc\mol\Assets\MoL\Scripts\**` (and its `Tests/` counterpart)
   where relevant — to confirm generalized usage descriptions still match how the type is
   actually used, without ever naming, quoting, or making that project identifiable (see the
   MoL rule in `TSVRC-DOCUMENTATION-PLAN.md` — it applies identically here).
4. `.claude/rules/writing-style.md` and `.claude/rules/doc-structure.md`.

A row is only checked once the assigned pages have been read line-by-line against their
source, not skimmed.
