# Hello, TsVRC

TsVRC is an independent, community-maintained framework for building VRChat worlds.
It is not affiliated with or endorsed by VRChat Inc. Its docs live here, under `docs/tsvrc/`.

When another project joins the `tsvrc` org, it gets its own folder next to this one
(`docs/<other-project>/`) — same repo, same site, no cross-repo wiring required.
