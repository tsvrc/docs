# Udon Tools Kit

Udon Tools Kit is a set of low-level UdonSharp tools for VRChat worlds, each built for Udon
performance and usable on its own. A world adds the component of a tool and wires it in the
inspector, with no base class to inherit and no setup object in the scene.

## Tools

- [EventEmitter](./reference/event-emitter) delivers named events to the behaviours subscribed to
  them, so the sender and its listeners don't reference each other.
