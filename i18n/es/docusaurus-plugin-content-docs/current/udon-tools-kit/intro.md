# Udon Tools Kit

Udon Tools Kit es un conjunto de herramientas de UdonSharp de bajo nivel para mundos de VRChat, cada
una pensada para el rendimiento de Udon y utilizable por sí sola. Un mundo añade el componente de
una herramienta y lo conecta en el inspector, sin clase base que heredar ni objeto de configuración
en la escena.

## Herramientas

- [EventEmitter](./reference/event-emitter) entrega eventos con nombre a los behaviours suscritos a
  ellos, para que quien los envía y quienes los escuchan no se referencien entre sí.
